## 先分清三种美国住宅 IP，别买错层级

“美国住宅 IP”在售卖页面上是同一个词，实际是三个层级，价格差得也很直白：68 元、169 元、599 元。

**双 ISP 住宅 IP** 是主流档。IP 的 ASN 类型和组织都带运营商属性，比单纯标一个“residential”更接近真实家庭用户，Scamalytics 这类欺诈风险评估里可以做到 0 分。丽萨的 9929 一期、4837、纽约、芝加哥都属于这一档。它跑在机房里，但 IP 属性是住宅加双 ISP。

**家宽 VDS** 是更高一档。机器直接托管在美国真实民房住宅中，走当地家庭宽带运营商的线路——西雅图是 Atlas Networks，加州是 Astound Broadband，另有加州的 T-Mobile/Frontier。IP 归属链路能对上具体的家庭宽带运营商，这跟“机房里挂着住宅属性的 IP”不是一回事。代价是带宽和流量限制更“真实”，而且这条线不是大陆直连优化网络。

**共享 NAT** 是另一个方向：不给你独享 IPv4，只分配共享 IP 上的 2/4/6/10 个 TCP/UDP 端口，带宽按 CN2 GIA 峰值给，明确禁止长时间占用。适合只需要一个稳定美国住宅出口、不需要独享 IP 和大带宽的场景，599 元/月起步，无退款。

多付的钱换到了什么，一句话概括：68 元买的是“平台看着像住宅”，169 元买的是“链路真的落在住宅”，599 元买的是“一个共享但真实的住宅出口”。买错层级比买错商家更常见，也更贵。

## FAQ

**双 ISP 到底怎么自己验？**
别只信一个工具。多个 IP 检测工具交叉验证，单一工具的结果容易被针对性优化；再查 IP 注册信息和路由轨迹，真住宅 IP 的归属链路能对上当地运营商宽带；最后在严格风控的平台实测，假住宅 IP 一用就露馅。下单前也可以开工单索要测试 IP，先用 ipinfo 查归属、Scamalytics 查风险分。多个第三方测评提到丽萨美国住宅 IP 段在 Scamalytics 的欺诈值为 0。

**能不能先买一个月测？**
可以，月付就是为这个准备的。常规线有 48 小时无理由退款，但不建议把退款当试用机制反复用。住宅 IP 资源各家批次有差异，先月付跑通业务环境，稳定了再上季付或年付拿折扣。

**48 小时退款怎么申请？**
提交工单给客服说明情况。注意家宽 VDS 只退网站余额，共享 NAT 不退，这两条线不适用无理由退款。

**能装 Windows 吗？**
大部分套餐支持，但需要提交工单走人工流程，不是面板一键重装，时间上要留余量。

**国内直连速度慢怎么办？**
先确认你买的是哪条线。家宽 VDS 本来就不是直连优化，官方建议配香港或日本 VPS 中转。9929 和 4837 是三网优化回程，直连表现正常；如果是移动用户遇上 38/154 段拥堵，工单换到 70/64 段。

**优惠码能叠加吗？**
能。9 折码和季付 9 折、年付 8 折、二年付 7 折叠加，最高到 6.3 折。记得在结算页点“验证”，看到优惠金额再付款。

**共享 IP 和独享 IP 差在哪？**
独享是分配给你一个独立 IPv4，所有端口归你；共享 NAT 是多人共用一个 IPv4，只给你 2/4/6/10 个 TCP/UDP 端口，带宽按峰值给且禁止长时间占用。前者适合跑完整业务，后者只适合需要一个稳定住宅出口的轻量场景。
